# h2-loadgen

Высокопроизводительный асинхронный нагрузочный HTTP/2-клиент на Python (`curl_cffi` + `asyncio`) для проверки собственного бэкенда.

## Что делает

Генерирует заданное число GET-запросов к целевому URL с ограничением в 15 параллельных потоков. Каждый запрос выполняется в чистой изолированной сессии, «личность» (прокси + браузерный профиль) выбирается случайно на каждый запрос. Ошибки подключения и таймауты не прерывают прогон — запрос молча пропускается, счётчик попадает в `failed`.

Особенности:

- **HTTP/2** — `http_version="v2"`, версия ответа проверяется (`resp.http_version`)
- **curl_cffi / libcurl-impersonate** — отпечаток TLS (JA3/JA4), порядок заголовков и SETTINGS HTTP/2 берутся из профиля `impersonate="chromeXXX"`
- **15 потоков** — `asyncio.Semaphore(15)`, без `sleep` и rate-limit
- **Изолированные сессии** — новая `AsyncSession` на каждый запрос, закрывается контекстным менеджером
- **Привязка прокси↔профиль** — пара (proxy, browser) фиксируется в `IDENTITIES` и выбирается на запрос, UA задаётся профилем и всегда соответствует ему
- **Тихий отказ** — `RequestsError` / `TimeoutError` / `OSError` ловятся, мёртвый прокси пропускается

## Установка и запуск

```bash
pip install -r requirements.txt
python loadtest.py
```

## Настройка

Константы в начале `loadtest.py`:

| Константа | Назначение |
|---|---|
| `TARGET_URL` | целевой URL (ваш сервер) |
| `TOTAL_REQUESTS` | общее число запросов |
| `MAX_WORKERS` | одновременных запросов (15) |
| `REQUEST_TIMEOUT` | таймаут запроса, сек |
| `HTTP_VERSION` | `v2` — принудительный HTTP/2 |
| `PROXY_LIST` | список прокси `http://user:pass@ip:port`, пустой = прямое соединение |
| `BROWSER_PROFILES` | профили браузеров для имперсонации |

## Ограничения

Скрипт предназначен для нагрузочного тестирования **собственных** ресурсов. Целевой сервер и канал должны быть ваши; имперсонация здесь — про реалистичность трафика, а не про обход чужой защиты.

## Требования

Python 3.10+, Windows/macOS/Linux (curl_cffi поставляет готовые сборки libcurl).
